Français

Créer une clé USB ou un disque chiffré

  1. Menu → Disques (GNOME Disques), choisir la clé.
  2. Sélectionner la partition → icône ⚙ → Formater la partition…
  3. Type : Disque interne à utiliser avec les systèmes Linux uniquement (Ext4) et cocher Volume protégé par mot de passe (LUKS).
  4. Choisir une phrase de passe longue (plusieurs mots), puis valider.

Une fois branchée, la clé demande sa phrase de passe dans le gestionnaire de fichiers. En ligne de commande : cryptsetup.

Chiffrer un fichier ou un dossier

  • Picocrypt (le plus simple) : glisser le fichier, choisir un mot de passe, Encrypt. Produit un fichier .pcv, à déchiffrer avec Picocrypt.
  • GPA (GnuPG) : chiffrer pour une personne avec sa clé publique, ou signer.
  • age, en terminal : age -p -o secret.age fichier puis age -d -o fichier secret.age.

Effacer les métadonnées avant de partager

Photos (position GPS, appareil), PDF et documents bureautiques (auteur, logiciel) contiennent des informations cachées. Metadata Cleaner : ajouter les fichiers, puis Nettoyer. En terminal : mat2 fichier.jpg (crée fichier.cleaned.jpg).

Vérifier un fichier téléchargé

GtkHash calcule l'empreinte SHA-256 d'un fichier, à comparer avec celle publiée par l'auteur.

Mots de passe

KeePassXC génère et garde vos mots de passe dans une base chiffrée. Enregistrez la base dans ~/Persistant (partition de persistance) pour la conserver.

Effacement : à savoir

Sur une clé USB ou un SSD, « effacer de façon sûre » (BleachBit, shred) n'est pas garanti : le matériel déplace les données. La seule protection fiable est de chiffrer dès le départ. EPIVÍOSI lui-même ne garde aucune trace en dehors de ~/Persistant : il suffit de redémarrer.

Documentation hors-ligne

Avec une connexion, epiviosi-security-docs ajoute à EPIVÍOSI WIKI (≈ 0,8 Go) : Information Security et Cryptography (questions-réponses Stack Exchange) et The OpSec Bible, en anglais. Ensuite : ouvrir la bibliothèque.

English

Create an encrypted USB stick or disk

  1. Menu → Disks (GNOME Disks), select the drive.
  2. Select the partition → ⚙ icon → Format Partition…
  3. Type: Internal disk for use with Linux systems only (Ext4) and tick Password protect volume (LUKS).
  4. Pick a long passphrase (several words) and confirm.

When plugged in, the file manager asks for the passphrase. Command line: cryptsetup.

Encrypt a file or folder

  • Picocrypt (simplest): drop the file, choose a password, Encrypt. Produces a .pcv file, decrypted with Picocrypt.
  • GPA (GnuPG): encrypt for someone with their public key, or sign.
  • age, in a terminal: age -p -o secret.age file then age -d -o file secret.age.

Remove metadata before sharing

Photos (GPS location, camera), PDFs and office documents (author, software) hold hidden information. Metadata Cleaner: add files, then Clean. Terminal: mat2 file.jpg (creates file.cleaned.jpg).

Verify a downloaded file

GtkHash computes a file's SHA-256 checksum, to compare with the one published by its author.

Passwords

KeePassXC generates and keeps your passwords in an encrypted database. Save it in ~/Persistant (persistence partition) to keep it.

Deletion: good to know

On USB sticks and SSDs, “secure deletion” (BleachBit, shred) is not guaranteed: the hardware moves data around. The only reliable protection is to encrypt from the start. EPIVÍOSI itself keeps nothing outside ~/Persistant: just reboot.

Offline documentation

While online, epiviosi-security-docs adds to EPIVÍOSI WIKI (≈ 0.8 GB): Information Security and Cryptography (Stack Exchange Q&A) and The OpSec Bible. Then: open the library.
